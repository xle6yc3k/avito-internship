# Система модерации объявлений (Avito Tech Internship)

Веб‑приложение для модераторов Авито, позволяющее просматривать,
фильтровать и принимать решения по объявлениям пользователей.\
Проект выполнен в рамках тестового задания на стажировку (Осенняя волна
2025).

------------------------------------------------------------------------

## 🧰 Технологический стек и обоснование выбора

### **Core**

-   **React 18** --- современная библиотека UI, используется
    конкурентный режим и автоматический батчинг.
-   **Vite** --- более быстрая альтернатива CRA, молниеносная сборка и
    HMR.

### **State Management & Data Fetching**

-   **TanStack Query (React Query)**\
    Стандарт индустрии для работы с серверным состоянием. Кэширование,
    дедупликация, invalidate‑логика, обработка состояний --- всё «из
    коробки».

### **Styling**

-   **Tailwind CSS**\
    Быстрое прототипирование + консистентная дизайн‑система через
    конфиг.

### **Routing**

-   **React Router v6**\
    Используются `useSearchParams` для синхронизации фильтров с URL.

### **Charts**

-   **Recharts** --- легковесная библиотека на React‑компонентах.

### **Utilities**

-   **Axios** --- базовый инстанс + интерцепторы.
-   **Lucide React** --- набор иконок.
-   **React Hotkeys Hook** --- декларативные горячие клавиши.

### **Infrastructure**

-   **Docker & Docker Compose** --- воспроизводимое окружение, запуск
    одной командой.
-   **Nginx** --- раздача статики SPA и прокси для API.

------------------------------------------------------------------------

## ⚙️ Установка и запуск

### **Вариант 1 --- Docker (рекомендуется)**

``` bash
docker-compose up --build
```

**Доступ:** - Frontend: http://localhost:80\
- Backend: http://localhost:3001

------------------------------------------------------------------------

### **Вариант 2 --- Локальная разработка (npm)**

### 1. Запуск Backend

``` bash
cd backend
npm install
npm run dev
```

Сервер будет доступен: http://localhost:3001

### 2. Запуск Frontend

``` bash
cd frontend
npm install
npm run dev
```

Приложение откроется по адресу из консоли (обычно
http://localhost:5173).

## ✨ Реализованный функционал

### **1. Главная страница --- Список объявлений (`/list`)**

-   [x] Адаптивная сетка карточек.
-   [x] Полная карточка объявления: фото, цена, категория, дата,
    статусы.
-   **Фильтры:**
    -   поиск по названию
    -   категория
    -   диапазон цен
    -   статусы (множественный выбор)
-   **Сортировки:**
    -   по дате
    -   по цене
    -   по приоритету
-   [x] Пагинация (10 элементов)
-   [x] Полная URL‑синхронизация

------------------------------------------------------------------------

### **2. Детальная страница (`/item/:id`)**

-   [x] Галерея изображений
-   [x] Полная информация об объявлении
-   [x] История модерации
-   **Панель действий:**
    -   Одобрить
    -   Вернуть на доработку
    -   Отклонить
-   [x] Переключение «Предыдущее/Следующее»
-   [x] Кнопка «Назад к списку»

------------------------------------------------------------------------

### **3. Страница статистики (`/stats`)**

-   Метрики: количество проверок, проценты одобрения/отклонения, среднее
    время проверки
-   Графики:
    -   активность (bar)
    -   решения (pie)
    -   категории (horizontal bar)
-   Фильтры периода: сегодня / неделя / месяц / произвольный диапазон

------------------------------------------------------------------------

### **4. Дополнительные возможности**

-   [x] Полная Docker‑инфраструктура\
-   [x] Настроенный Nginx\
-   [x] Адаптивная верстка\
-   **Горячие клавиши:**
    -   `A` --- одобрить
